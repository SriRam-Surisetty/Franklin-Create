# Franklin-Create
Demo website for Franklin Create

## PDF to Gemini App
A TypeScript React application that allows uploading PDFs and sending them to Google's Gemini AI for analysis.

### Setup
1. Navigate to the `pdf-gemini-app` directory.
2. Copy `.env.example` to `.env` and add your Gemini API key: `VITE_GEMINI_API_KEY=your_key_here`
3. Run `npm install`
4. Run `npm run dev` to start the development server.

### Usage
- Select a PDF file using the file input.
- Click "Analyze PDF" to send it to Gemini and get a summary.
